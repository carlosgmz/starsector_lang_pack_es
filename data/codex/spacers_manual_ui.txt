==Listas desplegables==
La barra de desplazamiento se amplía al acercar el ratón para facilitar el clic. También puedes mantener pulsada la tecla {{Shift}} mientras utilizas la rueda del ratón para desplazarte más rápidamente.

 ==Campos de entrada==
Puedes pulsar {{Ctrl-Retroceso}} para borrar una palabra, y {{Mayús-Retroceso}} para vaciar completamente el campo de entrada.

==Etiquetas==
Puedes pulsar {{Ctrl-clic}} para seleccionar varias etiquetas, o deseleccionar una sin afectar al resto de la selección.

==Intel==
Puedes pulsar {{Ctrl-S}} para guardar el conjunto de etiquetas actual, y {{Q}} para volver a seleccionarlo. También puedes pulsar {{Shift-Q}} para añadir el conjunto guardado a tu selección actual. Esto solo funciona con las etiquetas de la pantalla {{Intel}}.

==Codex==
Puedes pulsar {{F2}} en cualquier lugar para abrir el Codex. En muchos casos, por ejemplo en la pantalla de configuración o al consultar una ventana emergente, el Codex se abre automáticamente en la entrada correspondiente.
